# 插件清单与配置覆盖范围

> 本清单按当前工作区各服务端 `plugins/` 目录盘点。目录中有 JAR 或配置目录，不必然证明插件本次已成功加载；版本优先参考 JAR 文件名与服务端启动日志。具体开关、参数和指令请查对应插件页及配置文件。

## 一、网络端与认证

| 插件 | 所在端 | 用途 / 当前可确认配置 |
|---|---|---|
| AuthMe / AuthMeVelocity | sign、lobby1、survival / Velocity | 注册登录与代理认证转发；认证入口指向 sign，登录后配置跳转 survival |
| Sonar | Velocity、lobby1 | 代理连接验证与攻击期验证码 |
| VelocityReconnect | Velocity、lobby1 | 后端重启等待和自动重连 |
| ViaVersion | Velocity、lobby1 | 多版本协议转换；代理配置了 sign、lobby1、survival 对应映射 |
| SkinsRestorer | Velocity、lobby1、sign、survival | 玩家皮肤加载；日志显示代理模式，但共享数据库配置需要进一步核验 |
| Geyser / Floodgate | survival 目录存在 | 基岩版接入组件；目录不等于功能配置已启用，须确认代理和监听端口 |
| Simple Voice Chat / VoiceServer | 代理与 survival | UDP 语音转发；见 [聊天与社交](../player/聊天与社交.md) |

## 二、玩家核心功能

| 插件 | 配置/目录可确认的用途 |
|---|---|
| CMI + CMILib | 综合管理与玩家便利功能；经济提供器已启用，详见经济页和 CMI 配置 |
| LuckPerms | 权限管理；各后端配置为 global context、本地 H2 存储。不同后端数据是否同步需另行核实 |
| Vault、PlayerPoints | 经济接口、点券账户 |
| Residence | 领地保护；木锄选区，传送默认 3 秒，禁止未授权传送进入住宅 |
| QuickShop-Hikari | 箱子商店；基础税率 1%，由与商店交互的玩家承担，税收目标账户为 tax |
| GlobalMarketPlus | 全球市场、分类、收购/出售/拍卖/邮箱；具体税费和限制读取默认权限组配置，不以旧 Wiki 数值代替当前设置 |
| GuildPlugin | 公会、GUI、金库、角色和公会聊天；创建费用 5000，最多 50 名成员，最高 10 级 |
| BeautyQuests | NPC 任务、任务历史/进行中/可接取菜单；允许通过菜单取消任务，NPC 对话距离 15 格 |
| LiteSignIn | 签到 GUI、签到排行、补签卡；存储为 SQLite。签到奖励必须查看签到奖励配置，不能根据插件名称推断具体奖励 |
| VeinMiner | 潜行连锁采集；最大连锁 64，0 基础费用，类别由工具与方块清单限定 |
| MythicMobs | 自定义怪物、技能、物品、刷怪点；数据目录中存在副本相关定义 |
| ExecutableItems + SCore | 自定义可触发物品；EI 主配置没有全局禁用世界，实际物品效果须查看 `items/` 定义 |
| DeluxeMenus | 配置主菜单、点券、金币、礼包、活动、飞行等多个 GUI |
| Skript | 自定义脚本；scripts 目录可见菜单、死亡、跳跃、虚空传送、支付脚本等 |
| X-Chat | 聊天格式、提及、聊天标签、自动公告、PVP 死亡消息 |
| FlectonePulse | 全局聊天、社交趣味指令、聊天设置、气泡/提及；本地聊天及若干外部集成关闭 |
| TAB | 玩家列表页眉/页脚、头顶名称、延迟与生命显示；侧边栏、BossBar、布局和跨服玩家列表当前关闭 |
| GSit | 坐、躺、爬行、旋转等动作（以插件权限为准） |
| ZMusic | 点歌与音乐歌词/显示功能；点歌配置为扣款 10、冷却 5 秒，当前歌词总开关关闭 |
| zHead | 头颅目录、分类、搜索和获取指令；目录按字母、动物、方块、装饰、食物、人类、怪物、植物等分类 |
| ChatGames | 自动聊天小游戏；间隔 1231 秒，至少 2 人在线才启动 |
| CrazyCrates | 箱子抽奖系统；GUI 总菜单开关启用，抽奖权限采用旧式权限模式 |
| Citizens / dtlTraders / Shopkeepers | NPC 与商人相关组件；具体 NPC 和交易条目以各自数据目录为准 |
| BookNews | 书本/新闻内容组件；实际书目由其数据配置决定 |
| TogglePvp / FoPvPToggle | PVP 开关相关组件；存在两种名称相近的目录，实际注册命令须在游戏内核验 |

## 三、世界、建设与管理

| 插件 | 用途 |
|---|---|
| Multiverse-Core / Multiverse-NetherPortals | 多世界管理与下界传送门路由 |
| WorldEdit / FastAsyncWorldEdit | 管理员建筑编辑；注意权限控制与操作审计 |
| WorldGuard | 世界与区域保护 |
| CoreProtect | 方块/容器操作审计与回滚 |
| Chunky | 区块预生成/任务管理 |

| AdvancedBanZ、LiteBans、ZeFreeze | 处罚、封禁或冻结玩家；请先确认实际处罚存储与命令归属，避免多个系统重复管理 |

| MapArt、BillBoard、FancyDialogs、InteractiveChat、DamageIndicator | 地图/展示/对话/交互消息/伤害显示类组件；具体启用状态依各配置而定 |

## 四、当前明确的配置边界

- TAB 的 survival 与 lobby 页面眉/页脚、玩家名称格式、头顶队伍、列表 ping、血量显示已启用；记分板、BossBar、固定布局、跨服总列表关闭。
- X-Chat 启用玩家提及、可点击名字、自动链接、坐标/ping/物品聊天标签、随机公告；自定义表情和交互式 MiniMessage 标签关闭。
- FlectonePulse 关闭 Discord、Telegram、Twitch、DeepL、外部聊天同步和本地聊天；Simple Voice Chat、SkinsRestorer、LuckPerms、PlaceholderAPI、TAB 集成启用。
- LiteSignIn 的在线时长签到门槛关闭；签到提醒开启但自动签到关闭；补签卡启用，物品化补签卡关闭。
- 目录内还存在配置示例、语言文件、旧配置、缓存、统计 JSON、数据库及依赖资源。它们不是全部可供玩家使用的功能；未找到活跃配置的命令不会仅凭插件名字写成可用指令。
