## 二、进入服务器前置准备

1. 下载对应版本 Minecraft 客户端，推荐 **Minecraft Java 1.21.11**。
2. 账号注册与验证：
   - 首次进入：`/reg <你的密码> <重复密码>`
   - 再次进入：`/l <密码>`
   - 如果初次进入提示需要 `/login` 登录，说明有其他玩家在此之前注册了这个名称，请换一个名称再试。
3. 进入服务器后，**点击大厅 NPC** 传送到生存服务器。

## 四、玩家守则

### （一）禁止类行为

1. **作弊与外挂类**：使用外挂（如 Meteor Client 等）、矿透等破坏游戏公平性的功能。
2. **破坏与偷抢类**：恶意拆除他人建筑、窃取他人存储物品、破坏公共设施等恶意破坏性行为。
3. **影响服务器秩序类**：恶意刷屏、骚扰辱骂其他玩家、传播不良信息、恶意卡服等行为。
4. **规则套利类**：利用服务器 BUG 刷物品，未上报恶性 BUG 等。
5. **违规内容类**：搭建违规主题建筑、发布违规言论、引流其他非法服务器等。

### （二）鼓励类行为

1. 积极参与服务器公共建设、帮助新玩家熟悉规则等。
2. 主动上报服务器 BUG 与漏洞、举报违规行为等。
3. 创作优质建筑、游玩内容，合规宣传服务器内容。
4. 上述行为服务器会视情况给予奖励，包括游戏内货币、限定称号等。

## 五、违规处罚规则

| 处罚 | 适用情形 |
|---|---|
| **警告** | 首次刷屏、无意造成的少量破坏且态度良好 |
| **短期封禁（1-72 小时）** | 多次警告无效、恶意破坏但价值较低、辱骂他人且态度恶劣 |
| **永久封禁** | 传播违法信息；以下情形中拒不承认且无悔改态度或屡次违规 |

**永久封禁情形**：

1. 使用飞行、杀戮等严重外挂
2. 利用 BUG 大量刷取物品
3. 恶意卡服致服务器崩溃/回档

**申诉渠道**：寻找服务器管理员并附带申诉内容，见第七节。

## 六、特殊事项说明

1. **服务器更新与维护**：服务器维护/回档可能需要重启，具体情况会在群内提前说明。
2. **玩家隐私保护说明**：服务器仅记录与游戏运行相关的必要数据，包括：游戏 ID、可能的登录 IP、聊天记录、方块操作日志、物品交易记录。上述数据仅用于违规行为核查、纠纷解决及服务器安全维护。
3. **账号安全**：请不要将自己的游戏账号出借给他人，服务器不受理由此造成的封禁、损失。
