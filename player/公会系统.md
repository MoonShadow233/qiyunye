# 公会系统

> 栖云野使用 **GuildPlugin** 作为公会系统。玩家可以创建公会、邀请成员、升级公会、使用公会金库、公会聊天等功能。

---

## 一、快速开始

### 1. 创建公会

```
/guild create <公会名>
```

- 需要 **5000 金币**
- 公会名长度 **3 ~ 20 字符**
- 创建成功后，你自动成为**会长**

### 2. 打开公会菜单

```
/guild
```

菜单里可以查看公会信息、成员列表、金库、升级等。

---

## 二、公会基础

| 项目 | 限制 |
|---|---|
| 公会名长度 | 3 ~ 20 字符 |
| 公会标签长度 | 最长 6 字符 |
| 公会描述长度 | 最长 100 字符 |
| 最大成员数 | **50 人** |
| 创建费用 | **5000 金币** |
| 最高等级 | **10 级** |
| 公会标签颜色 | 金色（&6） |
| 公会名称颜色 | 黄色（&e） |

---

## 三、身份组

公会内有三种身份组：

| 身份组 | 颜色 | 权限 |
|---|---|---|
| **会长** | 金色 | 全部权限 |
| **官员** | 水蓝色 | 邀请、踢人 |
| **成员** | 灰色 | 基础权限 |

### 权限对照

| 权限 | 会长 | 官员 | 成员 |
|---|---|---|---|
| 邀请成员 | ✅ | ✅ | ❌ |
| 踢出成员 | ✅ | ✅ | ❌ |
| 晋升成员 | ✅ | ❌ | ❌ |
| 降职成员 | ✅ | ❌ | ❌ |
| 解散公会 | ✅ | ❌ | ❌ |

---

## 四、公会等级

公会最高 **10 级**。升级需要向公会金库存钱，存够升级费用后自动升级。

| 当前等级 | 升至下一级所需金币 |
|---|---|
| 1 级 | 5000 |
| 2 级 | 10000 |
| 3 级 | 20000 |
| 4 级 | 35000 |
| 5 级 | 50000 |
| 6 级 | 75000 |
| 7 级 | 100000 |
| 8 级 | 150000 |
| 9 级 | 200000 |
| 10 级 | 已满级 |

**升级方式**：

```
/guild deposit <金额>
```

---

## 五、常用指令

### 基础操作

| 指令 | 说明 |
|---|---|
| `/guild` | 打开公会主菜单 |
| `/guild create <名称>` | 创建公会 |
| `/guild info` | 查看公会信息 |
| `/guild list` | 列出所有公会 |
| `/guild leave` | 离开公会 |

### 成员管理

| 指令 | 说明 |
|---|---|
| `/guild invite <玩家>` | 邀请玩家加入 |
| `/guild accept` | 接受邀请 |
| `/guild kick <玩家>` | 踢出成员 |
| `/guild transfer <玩家>` | 转让会长 |

### 金库

| 指令 | 说明 |
|---|---|
| `/guild bank` | 查看公会金库 |
| `/guild deposit <金额>` | 向公会金库存钱 |

### 聊天

| 指令 | 说明 |
|---|---|
| `/guild chat <内容>` | 公会内部聊天 |

---

## 六、公会聊天

公会聊天有独立格式：

```
[公会] 会长 玩家名: 消息内容
```

**格式说明**：

| 部分 | 说明 |
|---|---|
| `[公会]` | 公会前缀 |
| `会长` / `官员` / `成员` | 身份组 |
| `玩家名` | 发送者名字 |
| `消息内容` | 消息正文 |

**支持彩色代码**：公会聊天里可以使用颜色代码。

---

## 七、公会金库

公会有一个**共享金库**，成员可以存钱，用于升级公会。

### 存钱

```
/guild deposit <金额>
```

### 查看金库

```
/guild bank
```

### 用途

- 升级公会
- 日后可能开放其他用途

---

## 八、公会传送

公会有**传送回家**功能，方便成员快速回到公会基地。

- 传送延迟：**0 秒**（即时）
- 具体指令见 `/guild` 菜单

---

## 九、公会 PVP

栖云野有独立的 **公会 PVP 世界** `guildpvp`。

- 公会之间可以在此切磋
- 具体规则日后公布
- 入口见 `/cd` 菜单

## 十、常见问题

**Q：创建公会要多少钱？**

A：**5000 金币**。

**Q：公会最多多少人？**

A：**50 人**。

**Q：公会最高几级？**

A：**10 级**。

**Q：怎么升级公会？**

A：`/guild deposit <金额>` 向公会金库存钱，存够升级费用后自动升级。

**Q：怎么邀请别人加入？**

A：`/guild invite <玩家>`。

**Q：怎么加入公会？**

A：收到邀请后 `/guild accept`。

**Q：怎么离开公会？**

A：`/guild leave`。

**Q：怎么查看公会信息？**

A：`/guild info`。

**Q：怎么查看所有公会？**

A：`/guild list`。

**Q：怎么在公会里聊天？**

A：`/guild chat <内容>`。

**Q：怎么转让会长？**

A：`/guild transfer <玩家>`。

**Q：公会有金库吗？**

A：有，`/guild bank` 查看。

**Q：怎么存钱到公会金库？**

A：`/guild deposit <金额>`。

**Q：公会有传送功能吗？**

A：有，`/guild` 菜单里有传送选项。

**Q：公会有排行榜吗？**

A：目前没有。

**Q：公会有 PVP 玩法吗？**

A：有，在 `guildpvp` 世界，具体规则日后公布。

**Q：怎么解散公会？**

A：会长可以用 `/guild` 菜单里的解散选项，或者用 `/guild delete`。

**Q：公会名能改吗？**

A：目前不支持改名。

**Q：公会标签是什么？**

A：公会标签是显示在玩家名字旁边的简称，最长 6 字符。

**Q：怎么设置公会标签？**

A：在 `/guild` 菜单里设置。

**Q：公会描述怎么改？**

A：在 `/guild` 菜单里设置，最长 100 字符。
