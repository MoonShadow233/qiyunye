# 自定义物品

> 栖云野使用 **ExecutableItems** 制作自定义武器。目前有 **6 把自定义武器**，全部通过副本 NPC 交易获得。

---

## 一、获取方式

所有自定义武器都通过 **副本 NPC 交易** 获得。

### 副本位置

| 副本 | 世界 | 特点 |
|---|---|---|
| 灰烬圣所 | `i1_world` | 骷髅王坐镇 |
| 松曦镇 | `i2_world` | 正在开发 |

### 进入副本

```
/cd → 副本
```

或

/warp i1_world
```

### 兑换流程

1. 进入副本
2. 找到副本出生点附近的 NPC
3. 与 NPC 交易
4. 用**副本材料**兑换武器

### 副本材料

副本材料通过击杀副本怪物获得，包括：

| 材料 | 说明 |
|---|---|
| 风蚀石 | 副本基础材料 |
| 野穗 | 副本基础材料 |
| 兽骨 | 副本基础材料 |
| 云絮 | 副本进阶材料 |
| 栖木枝 | 副本进阶材料 |
| 旧铁片 | 副本进阶材料 |
| 栖云石 | 副本稀有材料 |
| 金色棍子 | 副本稀有材料 |
| 归云令 | 副本稀有材料 |

## 二、自定义武器列表

### 1. 孔雀羽毛扇

| 项目 | 内容 |
|---|---|
| 材质 | 羽毛 |
| 名称 | &a孔雀羽毛扇 |
| 功能 | 右键向上二段跳 |
| 冷却 | 6 秒 |
| 消耗 | 无 |
| 描述 | 手持物品右键时，向上跳跃一次 |

**使用场景**：跑图、逃跑、PVP 走位。

### 2. 避雷针

| 项目 | 内容 |
|---|---|
| 材质 | 铜剑 |
| 名称 | &e避雷针 |
| 功能 | 攻击目标后 3 秒召唤闪电，对周围 8 格特定怪物造成 40 伤害 |
| 冷却 | 5 秒 |
| 消耗 | 无 |
| 描述 | 攻击目标时，延迟 3 秒后召唤闪电并对目标周围 8 半径内特定怪物造成 40 点伤害 |

**使用场景**：副本清怪。

**目标怪物**：骷髅、凋灵骷髅、史莱姆、猪灵、僵尸猪灵、僵尸。

### 3. 桃木剑

| 项目 | 内容 |
|---|---|
| 材质 | 木剑 |
| 名称 | &e桃木剑 |
| 功能 | 攻击目标时使目标飞起 |
| 冷却 | 6 秒 |
| 消耗 | 无 |
| 描述 | 攻击目标时，使目标飞起来 |

**使用场景**：PVP 控制、副本干扰。

### 4. 缓慢之剑

| 项目 | 内容 |
|---|---|
| 材质 | 铁剑 |
| 名称 | &b缓慢之剑 |
| 功能 | 攻击目标时施加缓慢 III + 发光，持续 6 秒；对半径 5 格僵尸、骷髅造成 2 伤害 |
| 冷却 | 无 |
| 消耗 | 无 |
| 附魔 | 锋利 V、耐久 I |
| 描述 | 攻击目标时，使目标获得缓慢 III、发光 BUFF，持续 6 秒；对半径 5 格内的僵尸、骷髅造成 ♥♥ 伤害 |

**使用场景**：副本清怪、PVP 减速。

### 5. 破旧不堪的金斧

| 项目 | 内容 |
|---|---|
| 材质 | 金斧 |
| 名称 | &6破旧不堪的金斧 |
| 功能 | 攻击目标时 1% 概率施加 10000 伤害 |
| 冷却 | 无 |
| 消耗 | 无 |
| 限制世界 | `i1_world`、`i2_world`、`instance` |
| 描述 | 在副本地图攻击目标时，有 1% 的概率施加 10000 伤害，否则不造成伤害 |

**使用场景**：副本打 Boss，欧皇专属。

**注意**：**只在副本世界生效**，普通世界无效。

### 6. 钻石权杖

| 项目 | 内容 |
|---|---|
| 材质 | 钻石锄 |
| 名称 | &b钻石权杖 |
| 功能 | 右键释放紫色魔法粒子，6 秒后对半径 50 格特定怪物造成 25 伤害 |
| 冷却 | 30 秒 |
| 消耗 | 无 |
| 描述 | 右键时，以自身为中心释放紫色魔法粒子；等待 6 秒后，对半径 50 格内特定怪物施加 25 伤害 |

**使用场景**：副本大范围清怪。

**目标怪物**：骷髅、凋灵骷髅、史莱姆、猪灵、僵尸猪灵、僵尸。

## 四、常见问题

**Q：怎么获得自定义武器？**

A：在副本 NPC 处用副本材料兑换。

**Q：副本 NPC 在哪？**

A：副本出生点附近。

**Q：需要什么材料？**

A：副本材料，通过击杀副本怪物获得。

**Q：孔雀羽毛扇怎么用？**

A：手持右键，向上二段跳。

**Q：避雷针怎么用？**

A：攻击目标后 3 秒召唤闪电，对周围 8 格特定怪物造成 40 伤害。

**Q：桃木剑怎么用？**

A：攻击目标使其飞起。

**Q：缓慢之剑怎么用？**

A：攻击目标时施加缓慢 III + 发光，持续 6 秒。

**Q：破旧不堪的金斧怎么用？**

A：攻击目标时 1% 概率造成 10000 伤害，**只在副本世界生效**。

**Q：钻石权杖怎么用？**

A：右键释放魔法粒子，6 秒后对周围怪物造成伤害。

**Q：武器有耐久吗？**

A：大部分自定义武器是**无限耐久**的，具体见武器描述。

**Q：武器能交易吗？**

A：可以，通过箱子商店或全球市场交易。

**Q：武器会掉落吗？**

A：死亡时**默认不掉落**，具体见武器设置。

**Q：武器有使用次数限制吗？**

A：大部分是**无限使用**，具体见武器描述。

**Q：武器能附魔吗？**

A：部分武器自带附魔，不能再额外附魔。

**Q：武器能修理吗？**

A：无限耐久的武器不需要修理。

**Q：武器能放进末影箱吗？**

A：可以。

**Q：武器能在领地内使用吗？**

A：可以，但领地内禁止 PVP 时，攻击玩家的技能无效。

**Q：副本材料能交易吗？**

A：可以，副本材料可以与其他玩家交易。

**Q：副本材料能兑换金币吗？**

A：目前不能直接兑换，但可以在全球市场出售。

**Q：怎么进入副本？**

A：`/cd` → 副本。
```
