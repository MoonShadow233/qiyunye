# 菜单与快捷操作

> 主菜单由 DeluxeMenus 提供。当前菜单配置中实际存在的按钮和操作如下；传送点需要在对应世界/权限可用时才能成功。

## 一、打开主菜单

- 输入 `/cd` 或 `/menu`。
- 潜行时按交换副手键会打开菜单；该操作会取消原版交换副手动作。
- 手持名称包含“右键菜单”的时钟右键也会打开菜单。
- TAB 页脚显示 `Shift + F`，但主菜单配置并未绑定该组合键；请以 `/cd`、`/menu` 或上面两个触发方式为准。

## 二、主菜单项目

| 菜单按钮 | 点击后的实际操作 |
|---|---|
| 玩家信息 | 显示玩家名、金币、点券和 UUID |
| 传送主城 | 执行 `mvtp 主城` |
| 主世界 | 执行 `rt world`，随机传送 |
| 下界 | 执行 `warp 下界` |
| 末地 | 执行 `warp end` |
| PVP 世界 | 执行 `warp pvp`；菜单标注该世界强制 PVP |
| 副本 | 执行 `warp i1_world`；菜单注明测试阶段 |
| 主城商店/建筑商店/杂货铺 | 分别执行 `warp shop`、`warp building_shop`、`warp 杂货铺` |
| 金币宝箱 | 执行 `warp 金币宝箱`；玩法与概率以游戏内宝箱提示为准 |
| 连锁采集 | 执行 `/veinminer toggle`；采集触发方式见[服务器特性](服务器特性.md) |
| 动作 | 打开动作菜单：坐、躺、趴、旋转 |
| 出售物品 | 执行 `sell gui` 打开出售界面 |
| 飞行控制 | 打开充能飞行界面；需要相应权限/插件支持 |
| 点券兑换 | 打开点券实体兑换菜单 |
| 金币兑换 | 打开金币实体兑换菜单 |
| 礼包 | 打开礼包中心 |
| 公会 | 执行 `/guild` |
| 好友 | 执行 `/f gui` |
| 反馈 | 执行 `/issue` |
| 自刎归天 | 执行 `/suicide`；确认后再用，可能导致正常死亡后果 |

> 菜单项执行服务器内部传送命令，世界名或传送点改动可能导致按钮暂时失效。菜单配置标注的“日后开放/测试阶段”不代表玩法一定处于正式开放状态。

## 三、金币与点券实体兑换

### 金币兑换

从 `/cd` 点击“金币兑换”。当前菜单面额为 **1、10、100、1000、10000 金币**；点击会从 Vault/CMI 余额扣除对应金额，并发放一张带有面额标记的实体纸币。

### 点券兑换

从 `/cd` 点击“点券兑换”，也可输入 `/dq`。当前面额为 **1、10、100 点券**；菜单使用服务器兑换命令扣点券并发放实体票据。

### 兑换回账户

右键带有“价值N金币”或“价值N点券”Lore 的票据，按票面值将金额兑换回账户，并消耗票据。不要用普通改名纸张代替服务器票据。

## 四、礼包中心

输入 `/libao`，或从 `/cd` 选择礼包：

- **新手礼包**：点击后调用 `/kit new`。菜单说明每人限领一次，最终领取限制由礼包系统执行。
- **签到礼包**：点击打开 `/signin gui` 签到日历。自动签到没有启用。
- **全部礼包**：点击执行 `/kit`，显示当前账号可用的礼包。

## 五、动作与飞行菜单

### 动作菜单

从 `/cd` 点击“动作”，可选择：

| 动作 | 菜单实际执行命令 |
|---|---|
| 坐下 | `/sit` |
| 躺下 | `/lay` |
| 趴下 | `/bellyflop` |
| 旋转 | `/spin` |

### 飞行控制

从 `/cd` 点击“飞行控制”：

- 左键充能飞行按钮：调用 `/flyc` 切换充能飞行。
- 右键：调用 `/recharge` 打开/使用充能界面。
- 查看充能：调用 `/fcharge`。
- 自动充能：调用 `/autorecharge exp` 切换经验自动补充。

菜单说明经验可用于充能、飞行会持续消耗充能，自动补充阈值和补充量以界面说明为准。是否可用取决于插件权限和经济/经验条件。

## 六、快捷键与客户端适配说明

主菜单配置能确认的快捷触发是“潜行 + 交换副手”和特定命名时钟右键。其他 GUI 按钮本质上是执行玩家命令；若点选无效，可在聊天栏直接尝试按钮显示的命令，并查看游戏内无权限/传送失败提示。
