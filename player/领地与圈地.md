# 领地与圈地

> 栖云野使用 **Residence** 作为领地保护插件。玩家通过木锄选角、指令创建的方式圈定自己的领地，保护建筑与箱子不被他人破坏。

---

## 一、快速开始

### 1. 获取选择工具

默认选择工具是 **木锄**。输入 `/res tool` 可获取一把。

### 2. 选择领地范围

手持木锄，**左键点击**一个方块作为第一个角，**右键点击**另一个方块作为第二个角。

- 两个角之间的立方体区域就是你要圈的地。
- 选择时会有**粒子边框**提示，方便你确认范围。

### 3. 创建领地
/res create <领地名>

领地名只能包含**英文字母、数字、连字符、下划线**，最长 64 字符。

创建成功后，领地立即生效，**按体积扣费**。

---

## 二、领地费用

| 项目 | 数值 |
|---|---|
| Default 组单价 | **0.01 金币/格** |
| 计费方式 | 按体积（X × Y × Z）计算 |
| 创建时扣费 | ✅ |
| 扩大时扣费 | ✅ |
| 添加区域时扣费 | ✅ |
| 删除领地退款 | ❌ 不退款（全局 `ResMoneyBack=false`） |

**例**：按 Default 组 `BuyCost=0.01` 估算，20×10×20 的领地共 4000 格，花费约 **40 金币**。最终金额以 `/res costs` 和创建时的服务端提示为准。

## 三、领地限制

| 项目 | 限制 |
|---|---|
| 最大领地数量 | **8 个** |
| 单个领地最大区域数 | **2 个** |
| 东西方向（X） | 最大 **300** 格，最小 **5** 格 |
| 南北方向（Z） | 最大 **300** 格，最小 **5** 格 |
| 上下方向（Y） | 最大 **384** 格，最小 **3** 格 |
| 最低保护高度 | **-64** |
| 最高保护高度 | **320** |
| 子区域最大数量 | 每个区域 **3 个** |
| 子区域递归深度 | **3 层** |

## 四、常用指令

### 基础操作

| 指令 | 说明 |
|---|---|
| `/res create <领地名>` | 创建领地 |
| `/res remove <领地名>` | 删除领地 |
| `/res tp <领地名>` | 传送到领地 |
| `/res tpset` | 设置领地传送点 |
| `/res info` | 查看当前所在领地信息 |
| `/res lists` | 列出你所有的领地 |
| `/res rename <旧名> <新名>` | 重命名领地 |
| `/res limits` | 查看你的领地数量上限 |
| `/res costs` | 查看圈地单价 |

### 权限管理

| 指令 | 说明 |
|---|---|
| `/res set <权限> true/false` | 设置所有人的权限 |
| `/res pset <玩家> <权限> true/false` | 设置指定玩家的权限 |
| `/res gset <组名> <权限> true/false` | 设置权限组的权限 |
| `/res gpset <组名> <玩家>` | 把玩家加入权限组 |

### 区域扩展

| 指令 | 说明 |
|---|---|
| `/res expand <长度>` | 向面朝方向扩大领地 |
| `/res subzone <子区域名>` | 在领地内创建子区域 |
| `/res area add <领地名> <区域名>` | 向领地添加新区域 |

### 其他

| 指令 | 说明 |
|---|---|
| `/res kick <玩家>` | 踢出领地内的玩家 |
| `/res give <玩家>` | 转让领地 |
| `/res message enter <文本>` | 设置进入欢迎语 |
| `/res unstuck` | 卡在领地里时脱困 |

## 六、权限组

Residence 支持把玩家分组，批量设置权限。

| 组名 | 作用 |
|---|---|
| `default` | 默认组，所有玩家 |
| `admin` | 管理组 |

### 设置组权限
/res gset <组名> <权限> true/false

### 把玩家加入组
/res gpset <组名> <玩家>


### 预置组

Residence 内置了几个常用组，可以直接使用：

| 组名 | 包含权限 |
|---|---|
| `trusted` | `use`、`tp`、`build`、`container`、`move`、`leash`、`animalkilling`、`mobkilling`、`shear`、`chat` |
| `redstone` | `note`、`pressure`、`lever`、`button`、`diode` |
| `crafting` | `brew`、`cartography`、`enchant`、`fletching`、`grindstone`、`loom`、`smithing`、`stonecutter`、`table` |
| `fire` | `ignite`、`firespread` |

## 七、子区域

子区域是领地内部的独立区域，可以单独设置权限。

### 创建子区域

1. 进入你的领地
2. 用木锄选一个范围
3. 输入 `/res subzone <子区域名>`

### 子区域限制

| 项目 | 限制 |
|---|---|
| 每个区域最多子区域 | **3 个** |
| 递归深度 | **3 层** |
| 子区域最大 X | **16 格** |
| 子区域最大 Z | **16 格** |
| 子区域最小 X | **3 格** |
| 子区域最小 Z | **3 格** |

### 子区域继承

子区域默认**继承父区域的权限**。如果不想继承，可以在 `config.yml` 里关掉 `ResidenceFlagsInherit`。

## 九、领地聊天

Residence 有独立的领地聊天频道。

### 加入领地聊天

进入领地后，输入 `/res chat` 加入。

### 发送消息

加入后，直接打字即可，只有领地内的人能看到。

### 退出领地聊天

再次输入 `/res chat` 退出。

## 十一、领地安全

### 防破坏

- 领地内默认**禁止外人建造**
- 领地内默认**禁止外人开箱子**
- 领地内默认**禁止外人使用门/按钮**
- 领地内默认**禁止 PVP**

### 防爆炸

- 领地内默认**禁止 TNT 爆炸**
- 领地内默认**禁止爬行者爆炸**

### 防液体

- 领地内默认**禁止液体流入**
- 领地内默认**禁止液体流出**

### 防怪物

- 领地内默认**允许怪物生成**（如果不想被刷怪，可以设置 `nomobs` 权限）

### 领地间距

领地之间默认至少间隔 **8 格**，防止领地背靠背。

## 十二、常见问题

**Q：怎么圈地？**

A：拿木锄左键点一个角，右键点另一个角，然后 `/res create 领地名`。

**Q：圈地要多少钱？**

A：Default 组当前配置为 **0.01 金币/格**。例如 20×10×20 共 4000 格，按此单价估算约 40 金币；以 `/res costs` 和创建时提示为准。

**Q：我能圈多少个领地？**

A：默认 **8 个**。

**Q：我的领地能有多大？**

A：单个区域最大 **300×384×300**，但你的领地可以有 **2 个区域**。

**Q：别人能进我的领地吗？**

A：默认**能进**，但不能建造、不能开箱子。你可以用 `/res set move false` 禁止他人进入。

**Q：别人在我的领地里打我怎么办？**

A：默认领地内**禁止 PVP**。如果有人能在你领地里打你，说明领地 `pvp` 权限被设成了 `true`。

**Q：领地内会刷怪吗？**

A：默认**会**。如果你不想被刷怪，可以用 `/res set nomobs true`。

**Q：怎么把领地给别人？**

A：`/res give <玩家>`。

**Q：怎么删除领地？**

A：`/res remove <领地名>`。注意**不退款**。

**Q：领地能卖吗？**

A：Residence 支持出售和出租，但栖云野**没有开放**。如果你想出售领地，可以联系管理。

**Q：卡在领地里怎么办？**

A：输入 `/res unstuck` 脱困。

**Q：领地名字能改吗？**

A：可以，`/res rename <旧名> <新名>`。

**Q：我的领地数量上限能提升吗？**

A：默认 8 个，无法提升。如果你需要更多，可以联系管理。

**Q：领地内的箱子会被偷吗？**

A：默认**不会**。只有你、你信任的人、以及被你设置 `container` 权限的人能打开。

**Q：领地内能放 TNT 吗？**

A：默认**禁止 TNT 爆炸**。即使你放了 TNT，爆炸也不会破坏方块。

**Q：领地内能刷怪吗？**

A：默认**允许**。如果你不想刷怪，可以 `/res set nomobs true`。

**Q：我能圈多大？**

A：单个区域最大 **300×384×300**。但你的领地可以有 **2 个区域**，所以理论上你能圈的面积很大。

**Q：领地到期会消失吗？**

A：Residence 有租赁系统，但栖云野**没有开放**。你的领地**不会自动消失**。

**Q：领地被别人占了怎么办？**

A：领地是**唯一**的，不能重叠。如果别人占了你想占的地方，你只能换地方。

**Q：领地能扩建吗？**

A：可以，`/res expand <长度>` 向面朝方向扩大。扩建会**扣费**。

**Q：领地内能飞行吗？**

A：默认**不能**。如果你有飞行权限（比如 VIP），可以设置 `/res set fly true` 让领地内飞行。

**Q：领地内能回血吗？**

A：默认**允许**。你可以设置 `/res set healing false` 禁止回血。

**Q：领地内能回饱食度吗？**

A：默认**允许**。你可以设置 `/res set feed false` 禁止回饱食度。
