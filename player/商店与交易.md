# 商店与交易

> 栖云野提供三种交易方式：**箱子商店**（QuickShop-Hikari）、**全球市场**（GlobalMarketPlus）、**玩家转账**（CMI 经济）。
>
> 本页面介绍这三种交易方式的使用方法。

---

## 一、箱子商店（QuickShop-Hikari）

### 1. 创建商店

**不需要指令**，按以下步骤操作：

1. 放置一个箱子
2. 手持想要出售的物品
3. **左键点击箱子**
4. 聊天栏输入**价格**
5. 把物品放进箱子

商店创建成功后，箱子上方会生成一个告示牌，显示商品信息。

**创建费用**：50 金币。

### 2. 购买物品

- **空手左键点击箱子**
- 聊天栏输入**购买数量**
- 回车确认

### 3. 商店模式

| 模式 | 说明 | 切换指令 |
|---|---|---|
| 出售 | 你卖东西给别人 | `/qs sell` |
| 收购 | 你收别人的东西 | `/qs buy` |
| 冻结 | 暂停交易 | `/qs freeze` |

### 4. 常用指令

| 指令 | 说明 |
|---|---|
| `/qs buy` | 切换为收购模式 |
| `/qs sell` | 切换为出售模式 |
| `/qs freeze` | 切换为冻结模式 |
| `/qs price <价格>` | 修改价格 |
| `/qs find <物品名>` | 查找附近商店 |
| `/qs remove` | 删除商店 |
| `/qs toggledisplay` | 切换悬浮物显示 |
| `/qs history` | 查看交易记录 |
| `/qs staff` | 查看商店员工列表 |
| `/qs refill` | 补充库存 |
| `/qs empty` | 清空库存 |

### 5. 交易税

箱子商店有 **1% 基础税率**，配置为对与商店交互的玩家计税；税额提示当前关闭，无限商店免此税。

### 6. 修改价格费用

修改商店价格需要支付 **100 金币**。删除商店不退创建费用。

### 7. 保护机制

- 箱子商店受保护，他人无法破坏
- 只有店主和员工能打开箱子
- 箱子商店不会被爆炸破坏

## 二、全球市场（GlobalMarketPlus）

### 1. 打开市场

```
/market gui
```

或

```
/gmp market
```

### 2. 出售物品

```
/market sell <价格> [数量]
```

**示例**：

- `/market sell 100` —— 以 100 金币出售手上的物品
- `/market sell 100 64` —— 以 100 金币出售 64 个

### 3. 收购物品

在市场中找到收购项，点击即可出售给收购方。

### 4. 拍卖物品

```
/auction start <价格>
```

拍卖功能：拍卖期间其他玩家可以竞价，价高者得。

### 5. 邮箱

```
/gmp mailbox
```

或

```
/mailbox
```

**邮箱用途**：

- 领取出售物品所得
- 领取购买的物品
- 领取系统奖励

### 6. 个人档案

```
/gmp profile
```

查看个人商户资料、商店设置、权限组等。

### 7. 交易税

GlobalMarketPlus 的 Default 默认组税率 **5%**（出售、收购、拍卖）。当前市场默认使用 Vault 金币，未启用多货币模式；出售和拍卖税在上架成交前收取，撤下商品不退已缴税款。

### 8. 商品有效期

| 类型 | 默认组 |
|---|---|
| 出售商品 | 10 天 |
| 收购商品 | 10 天 |
| 拍卖 | 3 分钟 |
| 邮件 | 15 天 |

### 9. 商品数量上限

| 类型 | 默认组 |
|---|---|
| 出售商品 | 10 个 |
| 收购商品 | 10 个 |
| 拍卖 | 2 个 |
| 邮件 | 30 个 |

### 10. 常用指令

| 指令 | 说明 |
|---|---|
| `/market gui` | 打开市场 UI |
| `/market sell <价格>` | 卖出手上物品 |
| `/market buy` | 购买物品 |
| `/gmp market` | 打开市场 |
| `/gmp mailbox` | 打开邮箱 |
| `/gmp profile` | 查看个人档案 |
| `/gmp transaction` | 查看交易记录 |
| `/gmp category switch` | 切换下一个有权限使用的市场分类 |
| `/pay <玩家> <金额>` | 转账给玩家 |

## 三、玩家转账

## 四、实体货币交易

栖云野支持把账户里的金币/点券兑换成**实体物品**，方便面对面交易。

### 兑换实体金币

```
/cd → 金币兑换
```

从 `/cd` 主菜单点击“金币兑换”。当前金币兑换菜单没有注册独立 `/jb_shop` 打开指令。

**面额**：1、10、100、1000、10000

### 兑换实体点券

```
/cd → 点券兑换
```

或

```
/dq
```

**面额**：1、10、100

### 兑换回账户

手持实体金币/点券，**右键**即可兑换回账户。

### 交易实体货币

实体货币可以：

- 直接丢给其他玩家
- 放进箱子
- 通过箱子商店出售
- 通过全球市场出售

## 五、主城 NPC 商店

主菜单配置了主城商店、建筑商店和杂货铺等传送入口；具体开放状态及商品以游戏内实际场景为准。

### 常见商品

- 食物
- 烟花
- 消耗品
- 建筑方块

### 进入方式

可从 `/cd` 主菜单点击对应商店按钮，也可尝试菜单配置使用的传送点命令，例如 `/warp shop`。若传送失败，以游戏内提示为准。

## 七、交易安全

### 防骗提醒

- 使用官方商店系统，不要私下交易
- 不要在聊天里点陌生链接
- 不要相信“先给钱后给货”的承诺

### 纠纷处理

如果交易出现纠纷：

1. 截图或录屏
2. 私聊群内管理
3. 管理会查 CoreProtect 记录处理

## 八、常见问题

**Q：怎么创建商店？**

A：放箱子 → 拿物品左键打箱子 → 聊天栏输入价格 → 放物品进箱子。

**Q：怎么购买？**

A：空手左键点击箱子，聊天栏输入数量回车。

**Q：怎么切换收购模式？**

A：`/qs buy`。

**Q：怎么切换出售模式？**

A：`/qs sell`。

**Q：怎么修改商店价格？**

A：`/qs price <价格>`。

**Q：怎么删除商店？**

A：`/qs remove`。

**Q：怎么查找商店？**

A：`/qs find <物品名>`。

**Q：怎么打开全球市场？**

A：`/market gui` 或 `/gmp market`。

**Q：怎么卖东西到全球市场？**

A：`/market sell <价格> [数量]`。

**Q：怎么查看市场邮箱？**

A：`/gmp mailbox`。

**Q：交易要交税吗？**

A：箱子商店基础税率 1%，对与商店交互的玩家计税；全球市场 Default 默认组出售/收购/拍卖税率 5%。

**Q：怎么转账？**

A：`/pay <玩家> <金额>`。

**Q：怎么把金币换成实体？**

A：打开 `/cd`，点击“金币兑换”。当前菜单没有独立 `/jb_shop` 打开命令。

**Q：怎么把点券换成实体？**

A：`/cd` → 点券兑换，或 `/dq`。

**Q：实体金币怎么用？**

A：右键实体金币，兑换回账户。

**Q：主城商店在哪？**

A：`/cd` → 主城商店，或 `/warp shop`。

**Q：副本 NPC 在哪？**

A：副本出生点附近。

**Q：怎么兑换自定义武器？**

A：副本 NPC 处用副本材料兑换。

**Q：交易被骗了怎么办？**

A：截图或录屏，私聊群内管理。

**Q：商店被破坏了怎么办？**

A：商店受保护，不会被破坏。如果真被破坏，联系管理查 CoreProtect。

**Q：全球市场商品过期了怎么办？**

A：过期的商品会下架，物品会通过邮箱返还。

**Q：邮箱满了怎么办？**

A：清理邮箱，或者等邮件过期自动删除。

**Q：怎么查看交易记录？**

A：`/qs history` 查看箱子商店记录，`/gmp transaction` 查看全球市场记录。
