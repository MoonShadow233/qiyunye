## 三、箱子商店（QuickShop-Hikari）

**创建商店不需要指令**：放箱子 → 拿物品左键打箱子 → 聊天栏输入价格 → 放物品进箱子。

| 指令 | 说明 |
|---|---|
| `/qs buy` | 把看向的商店切换为收购模式 |
| `/qs sell` | 把看向的商店切换为出售模式 |
| `/qs freeze` | 把看向的商店切换为冻结模式 |
| `/qs price <价格>` | 修改看向商店的价格 |
| `/qs find <物品名>` | 查找附近卖该物品的商店 |
| `/qs remove` | 删除你看向的商店 |
| `/qs toggledisplay` | 切换悬浮物显示 |
| `/qs history` | 查看商店交易记录 |
| `/qs staff` | 查看商店员工列表 |
| `/qs refill` | 补充库存 |
| `/qs empty` | 清空库存 |

**购买时**：空手左键点击箱子，聊天栏输入数量回车即可。

## 十六、常见问题

**Q：怎么圈地？**

A：拿木锄左键点一个角，右键点另一个角，然后 `/res create 领地名`。

**Q：怎么开商店？**

A：放箱子 → 拿物品左键打箱子 → 聊天栏输入价格 → 放物品进箱子。

**Q：怎么领签到奖励？**

A：输入 `/signin`。

**Q：怎么打开菜单？**

A：输入 `/cd` 或 `/menu`。

**Q：怎么查看自己的余额？**

A：输入 `/balance`。

**Q：怎么转账？**

A：`/pay <玩家> <金额>`。

**Q：怎么创建公会？**

A：`/guild create <名称>`，需要 5000 金币。

**Q：怎么进副本？**

A：`/cd` → 副本。

**Q：怎么反馈 BUG？**

A：`/issue`。
