## 三、箱子商店（QuickShop-Hikari）

**创建商店不需要指令**：放箱子 → 拿物品左键打箱子 → 聊天栏输入价格 → 放物品进箱子。

| 指令 | 说明 |
|---|---|
| `/qs buy` | 把看向的商店切换为收购模式 |
| `/qs sell` | 把看向的商店切换为出售模式 |
| `/qs freeze` | 把看向的商店切换为冻结模式 |
| `/qs price <价格>` | 修改看向商店的价格 |
| `/qs find <物品名>` | 查找附近卖该物品的商店 |
| `/qs remove` | 删除你看向的商店 |
| `/qs toggledisplay` | 切换悬浮物显示 |
| `/qs history` | 查看商店交易记录 |
| `/qs staff` | 查看商店员工列表 |
| `/qs refill` | 补充库存 |
| `/qs empty` | 清空库存 |

**购买时**：空手左键点击箱子，聊天栏输入数量回车即可。

## 十二、计分板（TAB）

当前 TAB 配置的 `scoreboard.enabled=false`，因此侧边栏及其 `/sb` 开关没有启用。TAB 管理命令 `/tab` 是管理用途，不作为普通玩家指令；玩家列表中的 ping/血量显示是自动呈现功能。

## 十三、连锁采集（Veinminer）

VeinMiner 配置的默认方式是按住潜行触发。`/veinminer` 相关子命令请以本服命令补全/插件帮助为准；当前配置能确认最大连锁量为 64，详见[服务器特性](服务器特性.md)。旧稿的“1000 个上限”已更正。

## 十八、常见问题

**Q：怎么圈地？**

A：拿木锄左键点一个角，右键点另一个角，然后 `/res create 领地名`。

**Q：怎么开商店？**

A：放箱子 → 拿物品左键打箱子 → 聊天栏输入价格 → 放物品进箱子。

**Q：怎么领签到奖励？**

A：输入 `/signin`。

**Q：怎么打开菜单？**

A：输入 `/cd` 或 `/menu`。

**Q：怎么查看自己的余额？**

A：输入 `/balance`。

**Q：怎么转账？**

A：`/pay <玩家> <金额>`。

**Q：怎么创建公会？**

A：`/guild create <名称>`，需要 5000 金币。

**Q：怎么进副本？**

A：`/cd` → 副本。

**Q：怎么反馈 BUG？**

A：`/issue`。

> 插件配置可能包含管理专用、未授权或冲突的命令。若指令不在 Tab 补全中，先查询对应插件帮助或询问管理，不要把管理命令当作玩家功能。
