# 任务与活动

> 栖云野使用 **BeautyQuests** 作为任务系统。服务器会不定期发布任务和活动，完成任务可获得金币、点券、物品等奖励。

---

## 一、任务系统

### 插件信息

| 项目 | 值 |
|---|---|
| 插件名 | BeautyQuests |
| 版本 | 2.1.0 |
| 作用 | 任务系统 |

### 打开任务列表

```
/quests
```

### 常用指令

| 指令 | 说明 |
|---|---|
| `/quests` | 打开任务列表 |
| `/quests start <任务名>` | 开始任务 |
| `/quests cancel <任务名>` | 放弃任务 |
| `/quests info <任务名>` | 查看任务详情 |
| `/quests journal` | 查看任务日志 |
| `/quests leaderboard` | 查看任务排行 |

---

## 二、任务类型

栖云野的任务分为以下几类：

### 1. 新手任务

新手进入服务器后可以接取的引导任务。

- **可接取次数**：每个玩家 **1 次**
- **奖励**：金币
- **内容**：简单的引导操作

### 2. 日常任务

服务器不定期发布的日常任务。

- **可接取次数**：每日刷新
- **奖励**：金币、点券、物品
- **内容**：打怪、采集、交易等

### 3. 活动任务

服务器活动期间限时开放的任务。

- **可接取次数**：活动期间
- **奖励**：活动限定物品
- **内容**：活动专属

---

## 三、任务奖励

完成任务可获得以下奖励：

| 奖励类型 | 说明 |
|---|---|
| 金币 | 通用货币 |
| 点券 | 高级货币 |
| 物品 | 装备、材料、消耗品 |
| 经验 | 原版经验 |
| 称号 | 限定称号（部分活动） |

---

## 四、活动

### 活动类型

栖云野会不定期举办以下类型的活动：

| 活动类型 | 说明 |
|---|---|
| 节日活动 | 春节、中秋、圣诞等 |
| 开服活动 | 服务器开服纪念 |
| 里程碑活动 | 玩家数破百、周年庆等 |
| 临时活动 | 管理临时举办 |

### 活动奖励

活动奖励通常包括：

- 限定称号
- 限定物品
- 大量金币/点券
- 特殊权限

### 活动通知

活动信息会在以下渠道发布：

- **QQ 群**：**1021999479**
- **游戏内公告**：X-Chat 自动公告
- **游戏内菜单**：`/cd` → 礼包

---

## 五、签到系统

栖云野集成了 **LiteSignIn** 签到系统。

### 指令

| 指令 | 说明 |
|---|---|
| `/signin` | 签到 |
| `/signin info` | 查看签到信息 |
| `/signin top` | 查看签到排行 |

### 奖励

- 每日签到可获得金币、点券
- 连续签到有额外奖励
- 具体奖励见签到界面

---

## 六、礼包系统

栖云野集成了礼包系统，通过 **DeluxeMenus** 实现。

### 打开方式

```
/cd → 礼包
```

或

```
/libao
```

### 礼包类型

| 礼包 | 说明 |
|---|---|
| 新手礼包 | 每人限领 1 次 |
| 签到礼包 | 每日领取 |
| 活动礼包 | 活动期间限时 |

### 领取方式

在礼包菜单里点击对应礼包即可领取。

---

## 七、任务建议

1. **先做新手任务**：进入服务器后第一时间完成新手任务，获得启动资金。
2. **每天签到**：签到是稳定的金币/点券来源。
3. **关注活动**：活动奖励通常比日常更丰厚。
4. **加群**：加入 QQ 群 **1021999479**，第一时间获取活动信息。

---

## 八、常见问题

**Q：怎么接任务？**

A：`/quests` 打开任务列表，选择任务。

**Q：任务奖励是什么？**

A：金币、点券、物品、经验等。

**Q：新手任务能做几次？**

A：每个玩家 **1 次**。

**Q：日常任务多久刷新？**

A：每日刷新。

**Q：怎么放弃任务？**

A：`/quests cancel <任务名>`。

**Q：怎么查看任务进度？**

A：`/quests journal`。

**Q：活动什么时候有？**

A：不定期，关注 QQ 群 **1021999479** 公告。

**Q：怎么签到？**

A：`/signin`。

**Q：签到奖励是什么？**

A：金币、点券，连续签到有额外奖励。

**Q：怎么领礼包？**

A：`/cd` → 礼包，或 `/libao`。

**Q：新手礼包能领几次？**

A：每人 **1 次**。

**Q：活动奖励什么时候发？**

A：活动结束后由管理统一发放。

**Q：任务做不完会消失吗？**

A：部分任务有期限，过期自动取消。

**Q：怎么查看任务排行？**

A：`/quests leaderboard`。
