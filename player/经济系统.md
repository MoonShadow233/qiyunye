# 经济系统

> 生存服通过 Vault 提供通用经济接口。当前 CMI 经济模块管理金币，PlayerPoints 管理点券。不同插件菜单可能采用不同货币，实际金额以游戏内余额和确认提示为准。

## 一、货币

| 货币 | 主要用途 |
|---|---|
| 金币 | 玩家转账、领地、箱子商店、公会和全球市场 |
| 点券 | 点券兑换菜单及活动/特殊兑换；是否可用于某项商品看菜单说明 |

当前 CMI 配置的金币新玩家起始余额为 100，最大余额 100,000,000；允许小数，最低转账金额 0.5。此为插件配置值，不保证既有玩家余额相同。

## 二、常用操作

| 指令或入口 | 说明 |
|---|---|
| `/balance` | 查看金币余额（若本服命令补全显示别名，以实际注册为准） |
| `/baltop` | 查看金币排行 |
| `/pay <玩家> <金额>` | 向玩家转账 |
| `/cd` → 玩家信息 | 菜单显示自己的金币与点券余额 |
| `/cd` → 金币兑换 | 把金币换成可交易的实体票据 |
| `/cd` → 点券兑换，或 `/dq` | 把点券换成实体票据 |

管理端的 `/eco`、`/money give/take` 等余额管理命令不属于玩家可用指令。

## 三、实体票据兑换

### 金币票据

从 `/cd` 打开“金币兑换”菜单。可兑换面额：**1、10、100、1000、10000 金币**。菜单会检查余额、扣除相应金币并发出服务器纸票。

### 点券票据

从 `/cd` 打开“点券兑换”，或输入 `/dq`。可兑换面额：**1、10、100 点券**。

### 票据兑现

手持服务器生成的金币/点券票据右键，系统依据票据 Lore 识别面额、把货币加回账户并消耗票据。普通纸张或自行改名的物品不能代替有效票据。

> 金币菜单文件没有注册独立 `/jb_shop` 打开命令；请从 `/cd` 进入。

## 四、玩家交易与市场费用

### 玩家转账

使用 `/pay <玩家> <金额>`。CMI 的 `/pay` 转账税当前关闭；插件设置最低支付金额为 0.5，并允许小数金额。确认转账前核对收款人和金额。

### QuickShop-Hikari 箱子商店

| 项目 | 当前配置 |
|---|---|
| 建立费用 | 50 金币 |
| 基础税率 | 1% |
| 计税对象 | 与商店交互的玩家 |
| 无限商店 | 免基础税 |
| 改价费用 | 100 金币 |
| 商店删除退款 | 不退款 |

税额显示开关当前关闭；实际扣费以结账提示和余额变动为准。详细操作见[商店与交易](商店与交易.md)。

### GlobalMarketPlus 全球市场

默认货币系统是 Vault，未启用多货币模式。Default 默认组的配置：

| 项目 | 数值 |
|---|---:|
| 出售税率 | 5% |
| 收购税率 | 5% |
| 拍卖税率 | 5% |
| 同时上架出售 | 10 件 |
| 同时发布收购 | 10 件 |
| 同时拍卖 | 2 件 |
| 邮箱上限 | 30 封 |
| 出售/收购有效期 | 10 天 |
| 邮件有效期 | 15 天 |
| 拍卖有效期 | 3 分钟 |

GlobalMarketPlus 配置出售与拍卖在完成交易前收税，撤下商品不退税款。VIP 组配置虽然存在，但能否使用取决于账号权限组，不能假定所有玩家拥有 VIP 额度或税率。

市场分类可用 `/gmp category switch` 切换；市场包含盔甲、武器、工具、食物、药水、方块、唱片、资源等分类。

## 五、领地与公会花费

| 项目 | 当前配置/说明 |
|---|---|
| Residence 圈地 | Default 组每格 0.01 金币；按选区收取，使用 `/res costs` 查看实际价格 |
| Residence 删除退款 | 关闭；删除领地不返还费用 |
| 创建箱子商店 | 50 金币 |
| 创建公会 | 5000 金币 |
| 公会升级 | 按等级存入金库，见[公会系统](公会系统.md) |

领地上限和单块尺寸也取决于 Residence 权限组；Default 组当前上限为 8 个领地。价格或权限若与旧文档不同，以游戏内命令提示为准。

## 六、玩家击杀结算

当前 Skript 对玩家击杀玩家事件按受害者**死亡前余额**计算：扣款 6%，击杀者奖励 3%。两项分别计算，低于 1 金币时各自归零。

脚本没有世界过滤条件，因此不能保证此结算只发生在 `pvp` 或 `guildpvp`；若玩家击杀在其他世界也触发，可能同样执行。该规则描述脚本配置，不构成对所有击杀事件均成功扣款的保证。

## 七、常见问题

**Q：怎么查看金币余额？**

A：`/balance`，也可打开 `/cd` 查看菜单里的玩家信息。

**Q：怎么转账？**

A：`/pay <玩家> <金额>`。

**Q：如何把金币/点券换成实体？**

A：金币从 `/cd` →“金币兑换”；点券从 `/cd` →“点券兑换”或 `/dq`。

**Q：实体票据怎么兑现？**

A：手持服务器生成的有效票据右键。

**Q：市场成交金额为什么有差异？**

A：可能涉及市场税、商品价格模式或邮件结算。Default 默认组税率为 5%；查看市场确认界面的最终金额。

**Q：怎么查领地价格？**

A：使用 `/res costs`；不同权限组可能不同。
