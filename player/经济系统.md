# 经济系统

> 栖云野使用 **Vault** 作为经济接口，**EssentialsX** 提供金币，**PlayerPoints** 提供点券。玩家通过打怪、任务、签到、交易等方式获得货币，用于购买物品、圈地、升级公会等。

---

## 一、货币种类

栖云野有两种货币：

| 货币 | 插件 | 用途 |
|---|---|---|
| **金币** | EssentialsX | 通用货币，圈地、商店、公会、转账 |
| **点券** | PlayerPoints | 高级货币，兑换稀有物品、特殊功能 |

---

## 二、金币

### 获取方式

| 方式 | 说明 |
|---|---|
| 打怪 | 击杀怪物掉落 |
| 任务 | 完成 BeautyQuests 任务 |
| 签到 | `/signin` 每日签到 |
| 卖东西 | 箱子商店、全球市场 |
| 活动 | 服务器活动奖励 |
| PVP | 击杀玩家获得对方 3% 金币 |
| 副本 | 副本 NPC 交易获得 |
| 连锁采集 | 挖矿、砍树获得（不直接给钱，但可以卖） |

### 消费方式

| 方式 | 说明 |
|---|---|
| 圈地 | Residence 领地，0.08 金币/格 |
| 箱子商店 | QuickShop 创建商店 50 金币 |
| 全球市场 | GlobalMarketPlus 交易税 5% |
| 公会 | 创建 5000 金币，升级最多 200000 金币 |
| 传送 | Essentials 部分传送收费 |
| 兑换 | `/jb_shop` 兑换实体金币 |
| 其他 | 部分插件功能收费 |

### 常用指令

| 指令 | 说明 |
|---|---|
| `/balance` | 查看余额 |
| `/baltop` | 查看财富排行 |
| `/pay <玩家> <金额>` | 转账给玩家 |
| `/eco give <玩家> <金额>` | （管理）给玩家金币 |
| `/eco take <玩家> <金额>` | （管理）扣玩家金币 |

---

## 三、点券

### 获取方式

| 方式 | 说明 |
|---|---|
| 签到 | `/signin` 每日签到 |

| 充值 | 通过赞助获得 |

## 四、实体货币

栖云野支持把账户里的金币/点券兑换成**实体物品**，方便交易。

### 兑换实体金币

```
/cd → 金币兑换
```

或

```
/jb_shop
```

**面额**：1、10、100、1000、10000

### 兑换实体点券

```
/cd → 点券兑换
```

或

```
/dq
```

**面额**：1、10、100

### 兑换回账户

手持实体金币/点券，**右键**即可兑换回账户。

## 五、PVP 经济

栖云野的 PVP 有经济惩罚和奖励。

### 死亡惩罚

| 项目 | 数值 |
|---|---|
| 死亡扣除 | 受害者余额的 **6%** |
| 击杀奖励 | 击杀者获得受害者余额的 **3%** |
| 余额不足 1 金币 | 不扣除 |

### 示例

- 受害者余额 10000 金币
- 死亡扣除 600 金币
- 击杀者获得 300 金币

**注意**：PVP 只在 `pvp` 和 `guildpvp` 世界生效，普通世界不会触发。

## 十、常见问题

**Q：怎么赚钱？**

A：打怪、任务、签到、卖东西、活动。最快的方式是开店卖东西。

**Q：金币和点券有什么区别？**

A：金币是通用货币，点券是高级货币，点券可以兑换稀有物品。

**Q：怎么查看余额？**

A：`/balance`。

**Q：怎么转账？**

A：`/pay <玩家> <金额>`。

**Q：怎么把金币换成实体？**

A：`/cd` → 金币兑换，或 `/jb_shop`。

**Q：怎么把点券换成实体？**

A：`/cd` → 点券兑换，或 `/dq`。

**Q：实体金币怎么用？**

A：右键实体金币，兑换回账户。

**Q：PVP 死亡会掉钱吗？**

A：会，死亡扣 6% 金币，击杀者获得 3%。

**Q：圈地要多少钱？**

A：0.08 金币/格。圈一个 20×10×20 的领地约 320 金币。

**Q：创建公会很贵吗？**

A：5000 金币。

**Q：开商店要钱吗？**

A：箱子商店创建费用 50 金币。

**Q：全球市场交易要交税吗？**

A：默认组税率 5%。

**Q：怎么查看财富排行？**

A：`/baltop`。

**Q：金币会过期吗？**

A：不会。

**Q：点券会过期吗？**

A：不会。

**Q：服务器会回收金币吗？**

A：服务器通过商店税、PVP 死亡扣款等方式回收金币，控制通货膨胀。

**Q：怎么赞助服务器？**

A：联系服主 LynOyo，或在 QQ 群内咨询。
