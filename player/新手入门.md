## 二、进入服务器前的准备

### 1. 下载客户端

下载对应版本的 Minecraft 客户端，推荐使用 **Minecraft Java 1.21.11**。

基岩版玩家也可以进服，版本要求 **1.21.11+**。

### 2. 注册与登录账号

第一次进入服务器时，需要注册账号：

```
/reg <你的密码> <重复密码>
```

之后每次进入服务器，使用以下指令登录：

```
/l <密码>
```

> 如果初次进入时提示需要使用 `/login` 登录，说明有其他玩家在此之前注册了这个名称，请换一个名称再试。

### 3. 进入生存服

进入服务器后，**点击大厅 NPC**，即可传送到生存服务器。

---

## 三、基础指令

指令中的尖括号 `<>` 表示**必填**，方括号 `[]` 表示**选填**。

### 常用指令

| 指令 | 说明 |
|---|---|
| `/cd` 或 `/menu` | 打开服务器菜单 |
| `/sethome [家的名称]` | 设置一个家 |
| `/home <家的名称>` | 传送到家 |
| `/dback` | 返回死亡点 |
| `/pay <目标玩家> <金额>` | 玩家转账 |

### 领地指令

| 指令 | 说明 |
|---|---|
| `/res create <领地名>` | 创建领地 |
| `/res tp <领地名>` | 传送到领地 |

### 市场指令

| 指令 | 说明 |
|---|---|
| `/market gui` | 打开全球市场 UI |
| `/market sell <价格> [数量]` | 卖出手上物品 |

## 四、新手建议

1. **先设家**：找到合适的地方后，第一时间用 `/sethome` 设置家，方便往返。
2. **圈领地**：用 `/res create` 保护你的建筑和箱子，避免被破坏或偷窃。
3. **看菜单**：`/cd` 里有服务器的大部分功能入口，不知道做什么就打开看看。
4. **加群**：加入 QQ 群 **1021999479**，服务器公告、维护通知、活动信息都会在群里发布。

## 五、玩家守则（简要）

完整守则请查看 [服务器守则](player/服务器守则.md)。

### 禁止行为

- 使用外挂、矿透等破坏公平性的功能
- 恶意拆除他人建筑、窃取他人存储物品
- 恶意刷屏、骚扰辱骂、传播不良信息
- 利用服务器 BUG 刷物品且不上报
- 搭建违规主题建筑、发布违规言论

### 鼓励行为

- 参与公共建设、帮助新玩家
- 主动上报 BUG 与漏洞
- 创作优质建筑与游玩内容
