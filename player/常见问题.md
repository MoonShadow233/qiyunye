# 常见问题

> 本页面收集栖云野玩家最常遇到的问题。如果这里没有你要找的答案，请加 QQ 群 **1021999479** 提问。

---

## 一、入门相关

**Q：服务器 IP 是什么？**

A：见交流群置顶公告。加群 **1021999479** 后查看群公告。

**Q：支持什么版本？**

A：MCJE 1.14.4 - 1.21.11，MCBE 1.21.11+。

**Q：怎么注册账号？**

A：第一次进服输入 `/reg <密码> <重复密码>`，之后每次进服输入 `/l <密码>` 登录。

**Q：提示需要 `/login` 登录怎么办？**

A：说明有玩家在你之前注册了这个名字，换一个名字再试。

**Q：怎么进生存服？**

A：进服后点击大厅 NPC，即可传送到生存服务器。

**Q：手机版能玩吗？**

A：可以，基岩版 1.21.11+ 支持进服。

## 二、基础操作

**Q：怎么打开菜单？**

A：输入 `/cd` 或 `/menu`。

**Q：怎么设置家？**

A：`/sethome` 设置当前位置为家，`/home` 传送回家。

**Q：怎么回家？**

A：`/home <家的名称>`，不填名称默认回第一个家。

**Q：怎么删除家？**

A：`/delhome <家的名称>`。

**Q：怎么查看所有家？**

A：`/homes`。

**Q：死亡后怎么回去？**

A：`/dback` 返回死亡点。

**Q：怎么传送给别人？**

A：`/tpa <玩家>` 请求传送到对方，`/tpaccept` 接受，`/tpdeny` 拒绝。

**Q：怎么转账？**

A：`/pay <玩家> <金额>`。

**Q：怎么看余额？**

A：`/balance`。

**Q：怎么看财富排行？**

A：`/baltop`。

**Q：怎么查看延迟？**

A：`/ping`。

**Q：怎么标记挂机？**

A：`/afk`。

**Q：怎么改昵称？**

A：`/nick <昵称>`。

**Q：怎么打开工作台？**

A：`/craft`。

**Q：怎么打开末影箱？**

A：`/enderchest`。

**Q：怎么查看坐标？**

A：`/getpos` 或按 F3。

**Q：怎么自杀？**

A：`/suicide`，用于卡墙、卡出生点等自救。

## 三、领地相关

**Q：怎么圈地？**

A：拿木锄左键点一个角，右键点另一个角，然后 `/res create 领地名`。

**Q：圈地要多少钱？**

A：按体积算，**0.08 金币/格**。

**Q：我能圈多少个领地？**

A：默认 **8 个**。

**Q：别人能进我的领地吗？**

A：默认能进，但不能建造、不能开箱子。

**Q：别人在我的领地里打我怎么办？**

A：默认领地内禁止 PVP。如果被打了，说明领地 `pvp` 权限被设成了 `true`。

**Q：怎么把领地给别人？**

A：`/res give <玩家>`。

**Q：怎么删除领地？**

A：`/res remove <领地名>`，注意不退款。

**Q：卡在领地里怎么办？**

A：输入 `/res unstuck` 脱困。

**Q：领地内会刷怪吗？**

A：默认会。不想被刷怪，可以 `/res set nomobs true`。

**Q：领地能扩建吗？**

A：可以，`/res expand <长度>` 向面朝方向扩大，扩建会扣费。

## 四、商店与交易

**Q：怎么创建箱子商店？**

A：放箱子 → 拿物品左键打箱子 → 聊天栏输入价格 → 放物品进箱子。

**Q：怎么购买？**

A：空手左键点击箱子，聊天栏输入数量回车。

**Q：怎么切换收购模式？**

A：`/qs buy`。

**Q：怎么切换出售模式？**

A：`/qs sell`。

**Q：怎么修改商店价格？**

A：`/qs price <价格>`。

**Q：怎么删除商店？**

A：`/qs remove`。

**Q：怎么查找商店？**

A：`/qs find <物品名>`。

**Q：怎么打开全球市场？**

A：`/market gui` 或 `/gmp market`。

**Q：怎么卖东西到全球市场？**

A：`/market sell <价格> [数量]`。

**Q：怎么查看市场邮箱？**

A：`/gmp mailbox`。

**Q：交易要交税吗？**

A：箱子商店基础税率 **1%**，全球市场默认组税率 **5%**。

## 五、经济相关

**Q：金币怎么获得？**

A：打怪、任务、签到、卖东西、活动奖励。

**Q：点券怎么获得？**

A：签到、活动、充值。

**Q：金币和点券有什么区别？**

A：金币是通用货币，点券是高级货币，可以兑换成实体物品。

**Q：PVP 死亡会掉钱吗？**

A：会，死亡扣 **6% 金币**，击杀者获得 **3%**。

**Q：怎么把金币换成实体？**

A：`/cd` → 金币兑换，或 `/jb_shop`。

**Q：怎么把点券换成实体？**

A：`/cd` → 点券兑换，或 `/dq`。

**Q：实体金币/点券怎么兑换回账户？**

A：右键实体金币/点券即可。

**Q：怎么签到？**

A：`/signin`。

**Q：怎么领新手礼包？**

A：`/cd` → 礼包 → 新手礼包，或 `/kit new`。

A：副本出生点附近。

**Q：副本能重复打吗？**

## 八、自定义物品

**Q：怎么获得自定义武器？**

A：在副本 NPC 处用副本材料兑换。

**Q：有哪些自定义武器？**

A：孔雀羽毛扇、避雷针、桃木剑、缓慢之剑、破旧不堪的金斧、钻石权杖。

**Q：孔雀羽毛扇怎么用？**

A：手持右键，向上二段跳。

**Q：避雷针怎么用？**

A：攻击目标后 3 秒召唤闪电，对周围怪物造成伤害。

**Q：桃木剑怎么用？**

A：攻击目标使其飞起。

**Q：破旧不堪的金斧怎么用？**

A：攻击目标时 1% 概率造成 10000 伤害，仅在副本世界生效。

**Q：钻石权杖怎么用？**

A：右键释放魔法粒子，6 秒后对周围怪物造成伤害。

## 九、服务器特性

**Q：拼刀怎么触发？**

A：被玩家攻击后 **4 游戏刻（约 0.2 秒）内**攻击对方。

**Q：拼刀有什么效果？**

A：受到的伤害会回补，反弹伤害 = **2.5 ×**（攻击者原本要造成的伤害 + 反击者对攻击者造成的伤害）。

**Q：连锁采集怎么用？**

A：`/cd` → 连锁采集开关，或者 `/veinminer toggle`。蹲下触发。

**Q：怎么坐下？**

A：`/sit`。

**Q：怎么躺下？**

A：`/lay`。

**Q：怎么爬行？**

A：`/crawl`。

**Q：怎么旋转？**

A：`/spin`。

**Q：怎么切换 PVP？**

A：`/pvp` 或 `/pvp on` / `/pvp off`。

## 十一、常见报错

**Q：提示“你没有权限”？**

A：该功能需要特定权限，联系管理确认。

**Q：提示“你输入得太快了”？**

A：聊天有 3 秒反刷屏限制，等一下再发。

**Q：提示“请不要使用过多的大写字母”？**

A：聊天有反全大写限制，正常打字即可。

**Q：提示“本服务器不允许发布广告”？**

A：聊天里不能发 IP 或 Discord 链接。

**Q：提示“你的消息包含被屏蔽的词汇”？**

A：消息里有敏感词，换一种说法。

**Q：进服后卡住不动？**

A：可能是网络问题，尝试重新进服。如果还卡，联系管理。

**Q：物品栏里的东西不见了？**

A：可能是死亡掉落、被偷、或者服务器回档。如果有疑问，联系管理查 CoreProtect 记录。

**Q：建筑被破坏了？**

A：如果圈了领地，领地内不会被破坏。如果没圈，联系管理查 CoreProtect 记录。
