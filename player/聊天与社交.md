# 聊天与社交功能

> 本页依据 survival 服的 FlectonePulse 与 X-Chat 配置整理。插件可能有同名/冲突命令；若游戏内 `/help` 或补全结果不同，以当前服实际注册为准。

## 一、聊天频道与格式

- FlectonePulse 的全局聊天已启用，范围是代理网络（`PROXY`），消息通过聊天栏发送；本地聊天模块当前关闭。
- FlectonePulse 的格式处理、提及提示、聊天气泡已启用。消息中的 `@玩家名` 会触发提及提示；格式模块支持颜色/渐变等 Adventure 标签。
- X-Chat 配置了 `admin` 与 `default` 两种格式。管理员格式优先级 100，普通格式优先级 1；是否使用取决于 `xchat.format.admin` / `xchat.format.default` 权限。
- 默认聊天格式不允许普通玩家输入传统颜色、Hex 或 MiniMessage 颜色代码；管理员格式允许。

## 二、玩家可用的社交与趣味指令

FlectonePulse 配置启用且权限默认允许玩家使用的主要命令：

| 指令 | 功能 |
|---|---|
| `/anon <内容>` | 以匿名玩家身份发送一条消息 |
| `/ball <问题>` | 询问魔法 8 号球，随机返回答复 |
| `/chatcolor` | 查看聊天颜色设置；`see` 是仅自己看到的颜色，`out` 是他人看到的输出颜色（输出颜色权限可能受限） |
| `/chatsetting` | 打开聊天显示设置，可选择聊天类型、颜色及消息通知项 |
| `/coin` | 抛硬币 |
| `/dice [骰子参数]` | 掷骰子并显示合计；参数格式以游戏内补全为准 |
| `/do <动作>` | 以角色扮演格式广播动作 |
| `/helper <内容>` | 发起求助请求 |
| `/ignore <玩家>`、`/ignorelist` | 屏蔽玩家或查看屏蔽列表 |
| `/mail` | 使用插件邮件功能 |
| `/me <内容>` | 以第三人称格式发送动作消息 |
| `/minesweeper` | 打开/游玩扫雷小游戏 |
| `/online`、`/ping` | 查看在线状态/网络延迟 |
| `/poll <内容>` | 发起聊天投票 |
| `/reply <内容>`、`/tell <玩家> <内容>` | 回复或发送私聊 |
| `/rockpaperscissors <玩家>` | 发起石头剪刀布 |
| `/sprite`、`/symbol` | 使用插件提供的图标/符号功能；具体参数用 Tab 补全查看 |
| `/stream` | 使用直播相关消息功能 |
| `/tictactoe <玩家>` | 发起井字棋 |
| `/toponline` | 查看在线时间排行 |
| `/translateto <语言> <内容>` | 请求将文本翻译为目标语言；服务支持受插件配置与依赖影响 |
| `/try <内容>` | 随机判断一件事是否成功 |
| `/whois <玩家>` | 查看插件支持的玩家资料（可见字段取决于权限） |

FlectonePulse 已启用的管理命令包括 `/ban`、`/banlist`、`/broadcast`、`/kick`、`/maintenance`、`/mute`、`/mutelist`、`/spy`、`/unban`、`/unmute`、`/warn`、`/warnlist`、`/whitelist`、`/geolocate` 等；这些属于管理功能，并非普通玩家命令。`/afk` 在 FlectonePulse 的命令配置中关闭，不能据此认定该插件提供此命令；服务器其他插件可能另有 AFK 命令。

> FlectonePulse 配置中启用不代表所有玩家都有权限：管理命令按 OP/权限节点保护。完整参数、权限不足时的正确语法可在游戏内输入命令不带参数并查看提示。

## 三、X-Chat 功能

### 聊天内标签

以下标签在聊天中启用，均需对应权限：

| 输入 | 效果 | 权限 |
|---|---|---|
| `[pos]`、`[coords]`、`[loc]` | 显示坐标和世界；悬停/点击可复制或填入坐标 | `xchat.tags.use` |
| `[ping]`、`[ms]` | 显示自己的延迟 | `xchat.tags.use` |
| `[item]`、`[物品]`、`[i]`、`[背包]`、`[手中]`、`[展示]` | 展示手持物品名称、数量、耐久、附魔和 Lore | `xchat.item.show` |

### 自动聊天增强

- 玩家名字悬停显示称号与 ping，点击名称会在聊天输入框建议 `/msg 玩家名 `。
- 自动识别消息中的玩家名称并高亮，播放提示音；配置为不要求 `@` 前缀。
- 自动识别 URL 并提示玩家谨慎打开。链接来自玩家输入，未知链接不要点击。
- 玩家输入的 MiniMessage 点击/悬停/插入/字体标签均关闭；自定义 Emoji 和自动语法纠正均关闭。
- 玩家私聊、回复、忽略等功能由插件命令提供；常用 `/msg`、`/w`、`/r`、`/ignore`。具体别名以命令补全为准。

### 自动公告与死亡消息

- X-Chat 自动公告已启用，每 300 秒随机发送一条，配置了包括圈地、商店、经济、菜单、聊天标签、群号等提示。
- X-Chat 自定义死亡消息只启用了玩家击杀（PVP）消息；摔落、怪物、溺水、火焰、岩浆、虚空等自定义死亡消息关闭，使用服务端/其他插件默认消息。

## 四、语音聊天

网络安装了 Simple Voice Chat，并在代理配置了 UDP 转发。语音连接依赖客户端安装兼容模组、网络 UDP 端口开放及配置的语音主机可达；Java/基岩客户端支持情况以群公告为准。没有语音图标或无法连接时，先确认客户端模组和 UDP 网络，而不是游戏 TCP 端口。
